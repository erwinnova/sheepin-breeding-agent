Sheepin Breeding Agent, test results

The same agent, the same 15 farmer notes (in Bahasa Indonesia, with English below; the agent replies in the farmer’s language), run against each model. A case passes when the agent makes exactly the expected record calls with the stated arguments, the backend accepts them, and when it should ask or refuse, it does. Back to the demo

How to read this

Each case lists the note, what the agent must do, and the outcome per model: the record calls made (lookups omitted), the agent's reply, and the time taken. Cases marked “must ask” or “must refuse” test that the agent does not invent data: missing lamb count, missing ram, unknown ear tag, a male recorded as the female, or a question outside breeding records. The clock is fixed so relative times (“tadi pagi”, “semalam”) are checkable. Results files are produced by run_tests.py and are not edited by hand.
